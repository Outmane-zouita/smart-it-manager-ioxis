# SMART IT MANAGER – IOXIS

Application statique prête pour GitHub Pages. Le point d’entrée du site est `index.html`.

## Données

Les tâches, incidents et paramètres sont conservés dans le stockage local du navigateur. Ils ne sont pas envoyés à GitHub et ne sont pas synchronisés entre les appareils. Utilisez l’export JSON de l’application pour sauvegarder ou transférer vos données.

## Publication

Le dépôt doit contenir `index.html` à sa racine. Dans GitHub, activez Pages depuis la branche `main`, dossier `/ (root)`. Le site sera alors disponible sur l’URL GitHub Pages du dépôt.
